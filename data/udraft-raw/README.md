# Underdog draft-room saves

Manually saved draft results/recap pages from Underdog (logged-in browser,
⌘S → HTML Only is fine). Parsed by the recap parser (issue #22); parsed
output lands in localStorage room records + exported `data/drafts/*.json`.

Filenames don't matter — the parser detects format by content. Raw pages are
gitignored (may contain room identifiers); this README stays tracked.
